# 下一站，和你 · 礼物网页 Demo

这是一份可继续修改的静态网页初稿：打开三张回忆卡片，收下线索并点亮三处地点，最后解锁礼物信。当前地点、故事、图片和礼物都是示例内容。

## 修改真实内容

- `dist/index.html`：首页文案、三个地点卡片上的标题与简介，以及最终礼物信的内容。
- `dist/script.js` 顶部的 `stories`：每处地点弹窗里的回忆、线索和图片路径。修改地点时，记得同步修改 `index.html` 中对应卡片。
- `dist/assets/`：替换成你们的真实照片。建议保留文件名直接替换图片，或同时更新 HTML 与 JS 中的路径。第一张最好用大学时期的第一张合照。
- `dist/styles.css`：颜色、字体、布局。当前用本机字体，不依赖在线字体服务。

进度只保存在打开网页的浏览器里。页脚“重新走一遍”可以清空进度。这个 Demo 没有上传照片、支付或外部账号功能。

本地预览：在 `SLS_MXY` 目录运行 `node serve.mjs`，打开 http://127.0.0.1:5200/ 。
