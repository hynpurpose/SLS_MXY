# 下一站，和你 · 回忆寻宝 Demo

这是一个可继续修改的单屏小游戏。玩家依次完成三关：在第一张照片里找物品、按顺序连起城市路线、交换海边照片碎片。三处地点点亮后解锁礼物。

## 换成你们自己的故事

- `dist/script.js` 顶部的 `scenes`：修改每关的标题、故事、任务、提示、过关线索和图片路径。第一、二关的 `targets` 中，`x`、`y` 是目标在照片中的百分比位置。
- `dist/index.html` 中的 `.journey-track`：修改顶部四个进度节点的名字；`#gift-reveal`：修改最终礼物。
- `dist/assets/`：放网页使用的图片。你新换的第一张插画已用于第一关；原始 PNG 保存在 `source-assets/hero-first-photo.png`，网页使用压缩后的 JPG。
- `dist/styles.css`：调整颜色和界面布局。

浏览器会记住已通关的关卡；右上角“重新开始”可以清空进度。当前第二、三关的地点和最终礼物仍是示例内容。

本地预览：在 `SLS_MXY` 目录运行 `node serve.mjs`，打开 http://127.0.0.1:5200/ 。
