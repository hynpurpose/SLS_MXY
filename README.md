# 礼物寄存站 · 2026 生日任务

这是独立于 `SLS_MXY` 首页的季节性小游戏。首页只需要一个普通链接指向本站；以后撤下活动时，删掉这个链接即可。

## 当前范围

- `dist/index.html`：前台与右侧线索房间两个独立场景、角色立绘、固定的三条线索进度，以及地图、地面物品、电视机三个入口。
- `dist/script.js`：夜班站长逐句对话；点击“开始寻找线索”后，站长退场并向右平移到线索房间。三个入口目前只打开预览提示，尚未完成关卡或计入进度。
- `dist/state.js`：独立的关卡编号与本地进度存储。今后的关卡可以调用 `completeStage('clue-1')` 等方法，并按顺序解锁。
- `dist/assets/`：手绘前台、右侧房间的桌面及手机画面、角色立绘。地面目前以信封、缎带、旧票和照片占位，后续可按确定的物品替换。

旧版小游戏使用的 `next-stop-game-v2` 浏览器记录不会影响当前进度。当前进度键为 `sm-birthday-2026:clues:v1`。

本地预览：在 `GiftGame` 目录运行 `node serve.mjs`，打开 http://127.0.0.1:5202/ 。
