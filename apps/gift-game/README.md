# 礼物寄存站 · 2026 生日任务

这是 `SLS_MXY` 仓库中独立于首页的季节性小游戏，位于 `apps/gift-game/`。首页只需要一个普通链接指向本站；以后撤下活动时，删掉这个链接即可。日常开发以合并后的仓库为准。

## 当前范围

- `dist/index.html`：前台与右侧线索房间两个独立场景、角色立绘、固定的三条线索进度，以及地图、地面物品、电视机三个入口。
- `dist/script.js`：夜班站长逐句对话；点击“开始寻找线索”后，站长退场并向右平移到线索房间。地图、地面物品、电视机在悬停或键盘聚焦时按物件轮廓发光，点击物件分别进入关卡；点击旁边的文字胶囊只显示提示与玩法。三个关卡都已接入。
- `dist/map-stage.js`、`dist/map-stage.css`、`dist/map-data.js`：第一关的独立地图册、NPC 玩法说明、17 张依次出现的白卡、拖拽放置、位置容差与图钉归位。每张照片都由玩家自行选择地图页；点击“下一张照片”后保持当前地图页和视角。地图同时标出目标城市和其他重要城市。
- `dist/photo-sources.js`：照片来源集中配置。现在是空对象，所以游戏显示真正空白的相纸；以后将照片放入 `dist/assets/photos/`，再按地点 ID 填写路径，即可原位替换，不必改动关卡逻辑或卡片排版。
- `dist/tv-stage.js`、`dist/tv-stage.css`、`dist/tv-order.js`、`dist/tv-tapes.js`：电视关的独立界面、录像播放、抽屉与顺序条。录像带可以拖进任意位置；放到已有带子的位置时，其他带子顺移；放好的带子也可以重新拖动或拖回抽屉。点带子可以反复观看。全部看过并放入后才可核对，错误排列会保留供继续调整。手机端还可用底部浮动按钮选择当前带子，再点击顺序位置；键盘可按空格选中带子。现在的六盘带子使用画面和时间占位。
- `dist/memory-stage.js`、`dist/memory-stage.css`、`dist/memory-items.js`：地面物品关采用 16 张卡片、8 对纪念物的翻牌配对。首次进入时随机排列；不计时、不限制次数；翻错后 1.2 秒自动翻回，期间不会接受第三张卡。配对后保持翻开并显示回忆，卡片和回忆册的小图都能再次查看；手机端会短暂浮出对应的回忆文案。8 对全部配成后解锁第二条线索。离开会翻回未配对的卡片，保留位置、已配对物品和回忆；键盘支持方向键移动，回车或空格翻牌，Escape 返回。
- `dist/assets/memory/`：8 件纪念物的独立 SVG 示意插画。真实照片准备好后，在 `dist/memory-items.js` 替换对应的 `image` 路径即可；同一配置也能修改物品名和回忆文案，无需修改配对逻辑。卡面包括自制专辑、一起挑中的领带、合照大相框、多美卡小车、梦露领带、双人成行、双境奇影和小动物蛋糕。
- `dist/state.js`：独立的关卡编号与当前页面内的进度。三个关卡可分别完成。
- `dist/assets/`：手绘前台、右侧房间的桌面及手机画面、角色立绘。地面目前以信封、缎带、旧票和照片占位，后续可按确定的物品替换。

本次生日游戏的线索、地图照片和 NPC 对话状态只在当前页面内保留；刷新或重新打开游戏会从头开始。旧版留下的浏览器记录不会被读取。第一关可在未完成时从第一张重新摆放，按钮需要连续点两次确认，同时会清除第一条线索的完成标记。

正常访问时，白卡及未放照片的进度不显示地名。暂时没有真实照片，需要核对开发占位时可打开 `http://127.0.0.1:5202/?mapDev=1`，右侧会额外显示当前白卡对应的地点；普通地址不会显示。日本「宇智」按确认后的「宇治」制作，海南的落点是三亚。地图册包括中国及周边国家的总图，以及江苏、湖南、福建、珠三角、海南岛、日本关西、杭州湾七张放大页。总图和各放大页都标有其他重要城市，照片与已钉相框不显示目的地文字。地图使用接近真实地理比例的画幅，城市之间没有路线连线。

地图素材由 [Natural Earth 10m 中国视角国家边界](https://www.naturalearthdata.com/blog/admin-0-countries-point-of-views/)与[省级边界](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)生成，已打包在 `dist/assets/`，本地运行无需联网获取地图。

真实录像准备好后，把视频文件放进 `dist/assets/videos/`，在 `dist/tv-tapes.js` 为对应带子填写 `src`，并按实际片段顺序更新 `sequence`。`label` 只标识录像带，不代表顺序；开发占位的时间只在播放后显示。播放器会自动使用真实视频，拖动排序逻辑不需修改。

照片替换示例：

```js
// dist/photo-sources.js
export const photoSources = {
  xuzhou: './assets/photos/xuzhou.jpg',
  osaka: './assets/photos/osaka.jpg',
};
```

## 本地访问

在 `SLS_MXY` 仓库根目录，用两个终端分别启动首页和游戏。无需安装依赖：

```sh
npm run dev:website
npm run dev:game
```

在同一台电脑的浏览器中打开首页 http://127.0.0.1:5200/ ，点击“解锁2026礼物线索”会跳转到独立的游戏地址 http://127.0.0.1:5202/ 。这两个服务都只在本机监听，不需要登录任何账号。以后部署到自己的服务器时，将 `apps/website/dist/index.html` 中该按钮的 `href` 改成游戏的实际地址即可。

也可以从仓库根目录直接运行 `node apps/gift-game/serve.mjs`；服务的素材目录根据脚本位置解析，不受运行目录影响。设置 `PORT` 环境变量可以改变本地端口。
